# 🍷 The Science Behind the Sip

### Wine Quality Prediction with Machine Learning

**Can chemistry predict what makes a better wine?**

This project explores the relationship between a wine's physicochemical properties and its quality rating. Using **Python, exploratory data analysis, statistical techniques, and machine learning**, I transformed chemical measurements into predictive models — uncovering which signals matter most when distinguishing wine quality.

## 🎯 The Challenge

Wine quality is influenced by multiple characteristics, from acidity and alcohol content to residual sugar and sulphates.

The goal was to investigate:

* Which chemical properties are most associated with wine quality?
* Can quality be predicted from physicochemical measurements?
* How does the problem change when approached as **regression vs. classification**?
* Which modeling approach produces the most useful predictions?

## 🔬 From Chemistry to Data

The analysis covers key wine characteristics including:

`fixed acidity` · `volatile acidity` · `citric acid` · `residual sugar` · `chlorides` · `density` · `pH` · `sulphates` · `alcohol`

The workflow included **data exploration, preprocessing, feature analysis, model training, and evaluation**.

## 🤖 Two Ways to Predict Quality

Instead of treating wine quality as only one type of machine-learning problem, I explored it from two perspectives.

**Regression** predicts the original numerical quality score, evaluated using metrics such as **MAE, RMSE, and R²**.

**Classification** groups wines into quality categories and predicts the resulting class, evaluated using metrics including **Accuracy and F1-score**.

This comparison highlights an important modeling lesson: **how you define the business question can be just as important as the algorithm you choose.**

## 🛠️ Tech Stack

**Python** · **Pandas** · **NumPy** · **Matplotlib** · **Scikit-learn** · **Machine Learning** · **Statistical Analysis** · **Data Visualization**

## 💡 Key Takeaway

Wine quality isn't explained by a single ingredient. It emerges from the interaction of several chemical characteristics.

By combining exploratory analysis with regression and classification, this project turns those chemical signals into something measurable and predictable.
